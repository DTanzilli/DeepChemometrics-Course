# DeepChemometrics Course

This repository contains Python notebooks and materials for the **Deep Chemometrics Course**.

## Contents

The repository includes Jupyter notebooks covering topics related to chemometrics, machine learning and deep learning for chemical data analysis.

### Notebooks

The notebooks are available in the [`notebook`](./notebook) folder.

- Notebook 1 – Introduction to Deep Learning using ANN
- Notebook 2 –  CCNs applications

## Requirements

To run the notebooks, you will need Python and Jupyter Notebook or JupyterLab.

Recommended Python packages include:

```bash
numpy
pandas
matplotlib
scikit-learn
jupyter
```

Additional libraries may be required depending on the notebook.

## How to use

Clone the repository:

```bash
git clone https://github.com/DTanzilli/DeepChemometrics-Course.git
```

Move into the repository:

```bash
cd DeepChemometrics-Course
```

Start Jupyter:

```bash
jupyter notebook
```

Then open the desired notebook from the `notebook` folder.

Alternatively, the notebooks can be viewed directly on GitHub without installing anything.
